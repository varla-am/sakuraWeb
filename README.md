<h1 align="center">Sakura</h1>

<p align="center">
  A minimal, private browser for macOS 🌸
</p>

## Features

- **🌸 Sakura Sidebar** — an Arc-style sidebar with vertical tabs and favorites.
- **⚙️ Sakura TrackerBlock** — blocks trackers and ads, and counts how many it stopped.
- **🧩 Safari Web Extensions** — runs the extensions you already use in Safari.
- **🔑 Sakura PassMan** — a password manager with AutoFill and CSV import from Apple Passwords or Chrome.
- **🛡️ Privacy** — Sakura never stores your browsing history.

## Requirements

- **macOS:** 26 Tahoe or newer
- **Mac:** Apple Silicon or Intel
- **Building from source:** Xcode 26 or newer
- **TeamID issue while building:** Project will not build with my _TeamID_, change it in _Signing & Capabilities_ in Xcode.

## Installation

1. Download `Sakura-v1.0.dmg` from [Releases](https://github.com/varla-am/sakuraWeb/releases).
2. Open it and drag **Sakura** into **Applications**.
3. On first launch Gatekeeper may block Sakura because it isn't notarized.
   Open **System Settings → Privacy & Security** and click **Open Anyway**.
